AK FOODS V4 – Tablet Full App
--------------------------------
Open index.html through a web address/HTTPS static host, then on Android Chrome choose Menu > Add to Home screen.
Features:
- Multi-item billing
- Customer name/phone
- Paid/due tracking and customer ledger
- Product inventory, stock-in, edit/delete, low-stock alert
- Purchase/selling price and profit
- Bill history
- Print / Save as PDF through Android print dialog
- CSV sales export
- JSON backup/restore
- Barcode camera field using BarcodeDetector where supported
- GST 0%
- Offline-friendly PWA cache + local browser storage

Important:
- This is a tablet web app/PWA, not an APK.
- Camera barcode scanning depends on browser/device support and usually requires HTTPS.
- Bluetooth ESC/POS printing is not implemented as a universal feature because browser/device support varies; Android print dialog can print to compatible printers.
- Data is stored locally in the tablet browser. Use Backup regularly.
